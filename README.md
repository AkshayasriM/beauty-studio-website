# ✨ ÉLVARA — Beauty & Wellness Studio

A premium, responsive beauty and wellness studio website designed with a sophisticated editorial aesthetic and smooth interactive experiences.

🌐 **Live Website:** https://beauty-studio-website-alpha.vercel.app/

---

## 📌 About the Project

ÉLVARA is a modern beauty and wellness studio website created as a frontend freelance project.

The website focuses on creating a premium digital experience through elegant typography, a refined color palette, responsive layouts, interactive sections, and smooth user interactions.

It is designed to help a beauty business showcase its services, build trust with visitors, and encourage appointment bookings.

---

## ✨ Features

- 🏠 Premium responsive landing page
- 💇 Interactive service cards
- 📸 Interactive image gallery
- 🔍 Image lightbox preview
- 📅 Appointment booking form
- ✅ Appointment success confirmation
- 📱 Responsive mobile navigation
- 💬 WhatsApp booking interaction
- 📧 Newsletter subscription interaction
- 🎞️ Scroll reveal animations
- 🔗 Smooth section navigation
- 📱 Mobile-first responsive styling
- ⚡ Fast Vite production build

---

## 🎨 Design

The interface uses a luxury-inspired visual direction with:

- Deep espresso
- Muted sage
- Warm ivory
- Champagne/gold accents
- Editorial-style typography
- Minimal layouts
- Soft hover interactions

The goal was to avoid the typical pink salon aesthetic and create a more sophisticated wellness-studio identity.
